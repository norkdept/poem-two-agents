A six-line poem about agency — the power to choose and to act — for make.fun's "The poem about two agents agreeing" bounty. Two agents agree on one plan at dusk; at dawn one walks through the door and the other holds it open, then lets it close. Holding the door is a choice too.

The text is 238 characters (Unicode code points), 6 lines, well inside the 1–280 gate.

## Run it

```sh
python3 main.py
```

It prints the poem and writes it to `/output/entry.txt` (0644, UTF-8, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write somewhere else. No network, no dependencies, Python 3.13.
